LEVEL 4 CURRICULUM

Advanced Technology Learning Journey

Level 4 introduces students to advanced programming, artificial intelligence, Generative AI, cybersecurity and real-world technology projects.

01

Advanced
Python

Topics

  • Advanced Python Introduction
  • Python Best Practices & Clean Code
  • Advanced variables & Data Types
  • Strings & Advanced Text Processing
  • Dictionaries & Nested Data Structures
  • Advanced Functions
  • File Handling & Data Processing
  • Exception Handling & Debugging
  • Python Libraries & APIs
  • Automation with Python

Practical Activity

  • Refactor an existing Python program
  • Work with type conversion and complex data structures
  • Solve data-processing problems using comprehensions
  • Read, write, filter, and analyze CSV datasets
  • Build a small OOP application
  • Create a simple CRUD-based database application
  • Develop and present a complete Python application
  • Create and use custom Python modules
02

Machine
Learning & AI

Topics

  • Advanced AI & Machine Learning Introduction
  • End-to-End ML Workflow
  • Data Preprocessing
  • Feature Engineering
  • K-Nearest Neighbors (KNN)
  • Support Vector Machines (SVM)
  • Model Evaluation & Validation
  • Deep Learning Basics
  • Natural Language Processing (NLP)
  • AI Ethics, Bias, Privacy & Responsible AI

Practical Activity

  • Build a complete ML pipeline
  • Clean and prepare a real dataset
  • Select and create useful features
  • Build a simple classification model
  • Improve a model using parameter tuning
  • Analyze ethical issues in an AI system
03

Generative
AI

Topics

  • Introduction to Generative AI
  • Generative AI Tools & Platforms
  • AI for Text Generation
  • AI Image Generation
  • Generative AI APIs
  • AI for Coding & Programming
  • Generative AI Capstone Project
  • AI Audio & Speech Generation
  • Large Language Models (LLMs)

Practical Activity

  • Explore real-world Generative AI applications
  • Understand the relationship between them
  • Understand how text-generation models work
  • Use role, context, constraints, and examples
  • Write effective prompts
  • Explore AI-generated speech and audio
04

Cybersecurity
& Ethical Hacking

Topics

  • Advanced Cybersecurity Introduction
  • Ethical Hacking & Cyber Laws
  • CIA Triad & Security Principles
  • Network Security
  • Networking Fundamentals for Security
  • Web Application Security
  • Security Scanning & Reconnaissance Concepts
  • Security Monitoring & Log Analysis
  • Cloud, Mobile & IoT Security
  • OWASP Top 10 Concepts

Practical Activity

Students use controlled educational environments to understand cybersecurity concepts safely.

  • Understand modern cybersecurity threats
  • Study authorization, ethics, and responsible disclosure
  • Understand IP, DNS, TCP/IP, ports, and protocols
  • Configure a firewall in an authorized lab
