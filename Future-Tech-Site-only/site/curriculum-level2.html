Curriculum

Learn programming, artificial intelligence, machine learning and cybersecurity.

01

Python
Basics

Topics

  • Introduction to Programming & Python
  • Python Setup & Coding Environment
  • Python Syntax, Keywords & Comments
  • Variables & Constants
  • Conditional Statements – if
  • Data Types
  • Input & Output
  • Operators
  • Strings & String Operations
  • if-else & elif

Practical Activities

  • Write your first Python program
  • Run Python using IDLE/VS Code
  • Identify syntax and write comments
  • Work with int, float, str, and bool
  • Create a greeting/name program
02

AI Tools &
ChatGPT

Topics

  • Introduction to AI
  • What is Generative AI?
  • Introduction to ChatGPT
  • Writing Effective Prompts
  • ChatGPT for Creative Writing
  • AI Presentation Tools
  • AI for Coding & Programming
  • AI for Language Learning
  • AI Safety & Privacy
  • Responsible & Ethical Use of AI

Practical Activities

  • Identify AI tools used in daily life
  • Explore how AI generates text and images
  • Understand prompts, AI models, and responses
  • Improve a weak prompt into a better prompt
03

Machine Learning
Basics

Topics

  • What is Machine Learning
  • AI vs ML
  • How Machines Learn
  • Data and Information
  • Features and Labels
  • Types of Data
  • Collecting Data
  • Understanding Datasets
  • Data Cleaning
  • Patterns in Data

Practical Activities

  • Identify ML examples in daily life
  • Compare AI and ML with examples
  • Human learning vs machine learning activity
  • Identify features and labels from examples
04

Cyber Security
Basics

Topics

  • Introduction to Cybersecurity
  • Why Cybersecurity is Important
  • Personal Information & Privacy
  • Strong Passwords
  • Password Security
  • Multi-Factor Authentication (MFA)
  • Safe Internet Browsing
  • Website Security & HTTPS
  • Antivirus & Device Protection
  • Wi-Fi & Network Safety

Practical Activities

  • Identify common online risks
  • Create examples of strong passwords
  • Understand how an extra verification step works
  • Identify HTTPS and the browser security indicators
05

AI Projects

Topics

  • AI Introduction Project
  • AI Chatbot
  • AI Quiz Generator
  • AI Story Generator
  • AI Image Creator
  • AI Voice Assistant Concept
  • AI Recommendation System
  • AI Plant Classifier
  • AI Health & Fitness Awareness
  • AI Cybersecurity Awareness

Practical Activities

  • Create a presentation showing how AI is used in daily life
  • Create a quiz using an AI tool
  • Create an interactive story with AI
  • Design a simple voice-assistant idea

Students progress from technology users to beginner technology creators, developing their first real programming and AI-based projects.
